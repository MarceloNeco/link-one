# LinkONE

O motor que liga os apps da SolverONE (e de clientes) às IAs: escolhe o provedor de cada pergunta, prefere os
grátis, respeita a privacidade de cada app e troca sozinho quando um provedor falha ou a cota acaba.

- Situação: **desenho pronto, aguardando a revisão do dono** — `docs/specs/2026-11-14-linkone-design.md`
- O que falta e o que espera decisão: `PENDENCIAS.md`
- Regras para quem mexe aqui (pessoa ou IA): `CLAUDE.md`

JavaScript puro, sem build, sem dependência, sem segredo no código.
